## Key Learnings

1. **gh CLI installation on headless server** — Download the tarball directly from GitHub releases (`gh_2.93.0_linux_amd64.tar.gz`), extract to `/tmp/`, copy the binary to `/usr/local/bin/`. No apt needed.
2. **gh requires `read:org` scope** — Even for personal repos! If the PAT doesn't have it, fall back to git credential store with `credential.helper store`.
3. **Git credential store on headless** — Write directly to `~/.git-credentials` as `https://username:token@github.com`, set `chmod 600`, and `git config --global credential.helper store`. Works reliably.
4. **GitHub no longer supports password auth** — Token-embedded URLs (`https://user:token@github.com/...`) in `git push` are rejected. Must use the credential helper.
5. **Cron job script path constraint** — Hermes cron's `script` parameter must be relative to `~/.hermes/scripts/`. Absolute paths are rejected. Create wrappers there.
6. **Cloudflare Tunnel is ephemeral** — Quick tunnels die when the session ends. Must restart cloudflared each time. Named tunnels with a registered domain would be permanent.
